# 手机版后台满宽自适应设计

## 目标

后台管理所有页面在手机端使用统一的满宽布局。外层页面只保留必要的 0-4px 安全边距，避免不同页面各自留下明显左右空白。

## 范围

本次只处理后台管理页面的移动端布局，不改变桌面端布局、菜单结构、接口逻辑和业务功能。

## 布局规则

- `AdminLayout` 作为统一入口，负责手机端后台内容区的外层宽度、边距和横向溢出控制。
- 手机端 `.admin-dashboard` 与 `.admin-content` 使用满宽显示，默认不额外添加大 padding。
- Element Plus 的卡片、表单、工具栏、分页和弹窗在手机端统一压缩边距。
- 表格和宽表单不撑开整个页面，改为在自身容器内部横向滚动。
- 页面局部样式仍可保留，但不得重新引入明显的左右外边距。

## 兼容策略

优先做全局后台移动端样式兜底，再针对已经发现问题的页面做少量修正。这样可以覆盖现有后台页面，也能减少后续新增页面再次出现左右留白。

## 验证标准

- 手机宽度下后台页面左右安全边距不超过 4px。
- 卡片和工具栏不再显著缩进。
- 表格可横向滚动，页面本身不出现明显横向撑破。
- 抽屉菜单仍保持默认隐藏、点击打开、点击关闭可用。
